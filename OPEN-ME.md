# Kade Studio, how to view the pages in VS Code

1. Open this folder in VS Code (File → Open Folder).
2. VS Code shows "This workspace has extension recommendations" → **Install All**. That installs **Live Preview** (Microsoft), which shows HTML pages inside VS Code.
3. Right-click any `.html` file → **Show Preview**. Or press `Ctrl+Shift+P` → "Live Preview: Start Server".

Pages worth opening:
- `kade-studio/brand/setup/gmail-setup.html` – create and set up kadestudio@gmail.com (checklist with copy buttons)
- `kade-studio/brand/fiverr/copy-page.html` – every Fiverr field, with copy buttons
- `kade-studio/index.html` – the website (FR), `kade-studio/nl/index.html` (NL)
